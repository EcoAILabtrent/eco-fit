## 2. Исправления узбекского

- `home.mealPicker`: сейчас = `home.nutrition` («Ovqatlanish»/«Овқатланиш») —
  два разных понятия одним словом. Заменить на «Ovqat qabuli» / «Овқат қабули».
- `health.deleteEntryConfirm`: «Ushbu yozuvni o'chirilsinmi?» — грамматическая
  ошибка (винительный + пассив). → «Ushbu yozuv o‘chirilsinmi?» / «Ушбу ёзув ўчирилсинми?».
- `nutrient.fiber`: «Kletchatka»/«Клетчатка» — русизм. → «Tola» / «Тола».
- `profile.goalGain`: «Massa yig'ish» → «Massa orttirish» / «Масса орттириш».
- `food.inMeal`: «Qabulda: …» — калька. → «Taomda: {count} · {kcal} kkal» / «Таомда: …».
- Месяцы uzCyrl (`_monthsFull`, `_months`): «Январ/Феврал/Апрел/Июн/Июл/Сентабр/
  Октабр/Ноябр/Декабр» — транслит с латиницы. Нормативно с мягким знаком:
  Январь, Февраль, Март, Апрель, Май, Июнь, Июль, Август, Сентябрь, Октябрь,
  Ноябрь, Декабрь (сокращённые — соответственно). Также `Филтрлар` → `Фильтрлар`
  (если ключ есть — поищи «Филтр»).
- **Апострофы в uzLatn**: сейчас вперемешку 5 символов (U+0027, U+2018, U+2019,
  U+02BB, U+02BC). Привести к норме: **U+02BB (ʻ)** для oʻ/gʻ, **U+02BC (ʼ)**
  для тутук белгиси (maʼlumot). Прогнать автозаменой по всему блоку uzLatn,
  затем глазами проверить границы кавычек “…” (их не трогать).
- `ai.robotHint` uzCyrl: «Eco Health‘даги» — латинская кавычка в кириллице.
  → «Eco Health иловасидаги ИИ-ёрдамчингизман» (перефраз без апострофа).

## 3. Плюрализация

`format()` — плоский replaceAll, из-за чего «21 лет», «осталось 2 шагов», «1 steps».

- Добавить в `AppStrings`:
  ```dart
  String plural(String keyBase, int n) // выбирает keyBase.one/.few/.many
  ```
  Правило ru: n%10==1 && n%100!=11 → one; n%10 in 2..4 && n%100 not in 12..14 →
  few; иначе many. en: n==1 → one, иначе many. Узбекский (оба скрипта):
  числительное + ед. число — всегда one-форма (пусть .one=.few=.many).
- Завести формы для существующих проблемных ключей:
  - `profile.ageValue` → `profile.age.one` «{n} год», `.few` «{n} года», `.many» «{n} лет»
    (en: year/years; uz: «{n} yosh» / «{n} ёш» — без форм);
  - `notif.steps.nudge.body` (…{left} шагов) → шаг/шага/шагов, step/steps, qadam;
  - `notif.steps.goal.body` — аналогично.
- Старые одиночные ключи оставить (их пока используют экраны) — волна 2 переключит.
