## 2. health.dart

- **Заметки-пустышка**: `NotesField` — TextField без controller/onChanged, текст
  молча выбрасывается. Убрать поле с экрана BodyEntryScreen до появления
  функционала (сам виджет можно удалить).
- **Дата в будущем**: `_pickDate` ограничивает только год. После выбора клампить:
  `if (d.isAfter(DateTime.now())) d = DateTime.now();` перед setState.
- **Фейковые точки графика тела**: `_chartEntries` при <7 записях дорисовывает
  выдуманные (`first.weightKg - i*0.28`…), их можно «удалить» — но
  `deleteBodyEntry` возвращает false и ничего не происходит. Сделать:
  сгенерированные точки рисовать полупрозрачными/пунктиром, не давать выбирать
  тапом и не показывать для них корзину; обрабатывать false от deleteBodyEntry
  (snackbar). Лучше вообще не дорисовывать — покажи столько точек, сколько есть.
- **«Нормы» тела захардкожены** (вес 53.5–72.3 и т.п. для всех): считать от
  профиля — вес по BMI 18.5–25 от роста (`heightCm` в store), мышцы/жир по полу.
  Формулы добавить в `lib/nutrition/energy.dart` (файл в этой задаче свободен) с
  doc-комментариями и источником.
- **Мёртвый код**: `NumberWheel`, `UnderlineInput` не используются (у второго —
  TextEditingController в build без dispose). Удалить.
- **watch → select**: `WaterScreen` и `BodyScreen` подписаны
  `context.watch<AppStore>()` — перестраиваются на каждый тик шагомера. Заменить
  на точечные `context.select` (hash нужных полей — образец в home.dart).
- Контроллеры в `_pickMetric`: FixedExtentScrollController без dispose —
  дispose через whenComplete (как в T5).

## 4. notification_settings.dart (+ дубль в profile.dart)

Мастер-тумблер включается локально, а `requestPermission()` вызывается без
await — при отказе в системном диалоге тумблер остаётся «включён», уведомления
не приходят.
- `final ok = await NotificationService.instance.requestPermission();
  if (!ok && mounted) { store.setNotifPrefs(enabled: false); }` + снекбар с
  подсказкой открыть системные настройки. Поправить в обоих местах.

## 5. lib/ai/**

- **Ошибки только на английском**: `_functionError` показывает серверный
  message как есть; fallback-строки англоязычные. Маппить `error.code` на ключи
  `ai.error.*` из new_keys.md; серверный message — только в debugPrint.
- **Апострофы**: в `ai_advice_service.dart` узбекские строки с U+02BC вместо
  U+02BB ('yoʼq', 'moʼljal') — привести к конвенции U+02BB (см. T4).
- **Двойная DNS-проверка**: экран вызывает `_checkOnline()`, затем
  `fetchDailyAdvice` снова `hasInternet()` — до 4 лишних секунд. Убрать
  предварительную проверку из fetchDailyAdvice (SocketException и так
  обрабатывается) — оставить одну, на экране.
- Клиентский таймаут `AiConfig.timeout` поднять до 40 с (сервер умирает на 30-й —
  дать серверной ошибке шанс дойти).
