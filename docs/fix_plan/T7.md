## 1. ГЛАВНОЕ: Consumer<AppStore> вокруг MaterialApp

`main.dart`, `EcoApp.build`: `Consumer<AppStore>` подписан на ВСЕ уведомления
стора, а шагомер тикает несколько раз в секунду при ходьбе. Каждый тик —
пересборка MaterialApp + новый ThemeData + `ColorScheme.fromSeed` (дорогая
генерация палитр). Вся select-гранулярность экранов обесценена.

- Заменить на точечные подписки:
  ```dart
  final t = context.select<AppStore, EcoTheme>((s) => s.theme);
  final lang = context.select<AppStore, AppLanguage>((s) => s.language);
  ```
- ThemeData кешировать по идентичности темы (например, static Map<EcoTheme,
  ThemeData> или два поля light/dark) — fromSeed не должен звать каждый build.
- Заодно: экран ошибки старта в main.dart захардкожен по-английски
  ('Could not start Eco Fit.', 'Retry') — использовать ключи `startup.error`/
  `startup.retry` из new_keys.md; если store недоступен — выбрать язык по
  `PlatformDispatcher.instance.locale` из статической мини-карты.

## 2. Покадровый BackdropFilter σ60 в модалках

`ui.dart`, EcoGlassSurface/showEcoSheet: комментарий «эти окна не скроллятся»
неверен — внутри крутятся CupertinoPicker-барабаны, и σ60-блюр пересчитывается
каждый кадр прокрутки (тот же класс лагов, что чинили в коммите 6fe473a).
- Для шитов/попапов отказаться от живого блюра: solid-заливка (как у нижнего
  нава в _LiquidNavBand) ИЛИ sigma 60 → 15 (визуально неотличимо на матовой
  подложке). Выбери вариант по красоте, но живой σ60 не оставляй.
- `BackdropGroup` обёрнут вокруг 4 экранов, но `BackdropFilter.grouped` не
  используется нигде — это no-op. Либо перевести единственный BackdropFilter на
  `.grouped`, либо удалить все 4 обёртки (проверь addfood/onboarding/profile —
  их файлы не в этой задаче, поэтому если обёртки там, просто оставь и опиши в
  коммите; убери хотя бы в ui.dart).

## 6. home.dart

- `context.watch<AppStore>()` в `MealPickerHost`/`_MealPickerSheet` —
  перестройка панели 432px на каждый тик шагомера. → `context.select` по
  diaryRevision + theme, store через context.read.
- Вес «66.0 кг» с точкой на карточке тела: форматировать через `num1()`
  (66 / 66,5). Заодно «BMI» → «ИМТ» для ru (возьми ключ из new_keys.md, если
  T4 его завёл; иначе оставь BMI).
- Жёсткие высоты и системный шрифт: панель приёмов `height: 432`, строки
  `SizedBox(height: 46)`, бейдж 37×37 — при textScale 1.3+ overflow. Минимум:
  обернуть компактные элементы в `MediaQuery.withClampedTextScaling(
  maxScaleFactor: 1.2, ...)`; высоту панели считать от контента, где несложно.
