## 1. Захардкоженный русский «Общее количество»

`dayview.dart` (~строка 193): `label: b.head ? 'Общее количество' : b.label` —
русский текст во всех локалях. Заменить на `l.t('common.totalAmount')` (ключ
уже добавлен). Дублирующиеся хелперы `_totalCaloriesLabel` в dayview.dart и
meallog.dart удалить, заменив вызовы на тот же ключ.

## 2. Дата-арифметика: DST и полночь

- `dayview.dart`: `DateTime.now().subtract(Duration(days: offset))` — Duration
  это ровно N×24ч, на переводе часов даёт соседнюю дату. Заменить на календарную
  арифметику: `final now = DateTime.now(); DateTime(now.year, now.month, now.day - offset)`
  (конструктор нормализует). Все места: `_selectedDate`, `_DayStrip`.
- `_DayStrip.build` вызывает собственный `DateTime.now()` — передавать `now`
  одним значением за build, чтобы подсветка и ключ данных не разъезжались на
  границе полуночи.
- Запись «в сегодня» через `date: null` (dayview.dart, места вызова
  MealLogScreen/AddFoodScreen): null разворачивается в `ymd()` в момент КАЖДОЙ
  операции — еда, добавленная в 00:01, уезжает в новый день, хотя экран
  показывает старый. Передавать конкретный `_dateKey` всегда (dayview его уже
  имеет); «null = сегодня» оставить только для входа с главного экрана.

## 3. Навигация: дубль журнала в стеке

`addfood.dart`, `_finish()`: `pushReplacement(... MealLogScreen(...))` — но
AddFood открывается и ИЗ MealLog, после чего в стеке два одинаковых журнала.
- Добавить в конструктор AddFoodScreen флаг `openLogOnFinish` (default true для
  маршрута с главного экрана). Если открыт из MealLog — `Navigator.pop(context,
  true)` (журнал перечитает store по diaryRevision). Проверь все точки входа.

## 4. Дубли кода → новые общие файлы

- `_TotalCaloriesSummary` (идентичен в dayview и meallog), `_ContributionRow` /
  `_MealMacroContributionRow` (одинаковый layout) → вынести в НОВЫЙ файл
  `lib/ui/nutrition_widgets.dart`, оба экрана используют общий.
- Карты цветов нутриентов разъехались: `_microColor` (dayview) vs
  `_nutrientColor` (dish) — vit_c жёлтый на одном экране и зелёный на другом.
  → единая `Color nutrientColor(String code)` в НОВОМ файле
  `lib/theme/nutrient_colors.dart`; выбери канонический цвет (возьми вариант
  dayview за основу), подключи в оба экрана.
- Три форматтера `_fmt`/`_fmtMacro` (dayview/meallog/dish) с разными порогами →
  заменить на `AppStrings.num1()`/`decimalSep()` из волны 1 (см. new_keys.md).
