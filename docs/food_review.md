# Проверка продуктов в браузере

Локальный редактор показывает изображения и названия всех 1122 продуктов на четырёх языках в одном скроллируемом каталоге.

## Запуск

Дважды нажмите:

```text
tooling\start_food_review.cmd
```

Или запустите из PowerShell в корне проекта:

```powershell
python tooling\food_review_server.py
```

Откроется `http://127.0.0.1:8765`. Окно PowerShell должно оставаться открытым во время работы.

## Работа

- Просматривайте карточки скроллом: на каждой видны фотография и названия `UZ`, `ЎЗ`, `RU`, `EN`.
- Поиск работает сразу по всем четырём языкам, категории и `slug`.
- Фильтр «Возможные ошибки» находит пустые поля, служебные заглушки, лишние пробелы и повторяющуюся пунктуацию.
- Нажмите карточку, чтобы изменить названия, категорию или заменить изображение.
- Кнопка «Удалить продукт» убирает запись из JSON и SQLite после подтверждения. Файл изображения остаётся в assets для безопасного восстановления.
- Сохранение сначала создаёт резервную копию, затем атомарно обновляет `assets/foods.json` и пересобирает `assets/db/eco_fit.db`.
- Быстрые клавиши: `/` — поиск, `Ctrl+Enter` — сохранить открытую карточку, `Esc` — закрыть редактор.

Резервная копия текущего сеанса хранится в `tooling/.food_review_backups/` и не добавляется в Git.
